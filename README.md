# Universal Software Standard (USS)

A real, adoptable engineering standard for all software, written in RFC 2119
terms. The promise: if a project follows every applicable rule, including
adopting every applicable MAY, it is as good as software can be made. It is
used in two ways. For a new project ("adopt"), a developer tells their agent to
comply with the standard, and the agent profiles the project, asks about every
applicable SHOULD, SHOULD NOT and MAY item, records the answers, and builds to
the result. For an existing codebase ("audit"), the agent scans the code, asks
the same questions, audits every applicable rule, reports, and fixes the
codebase toward compliance.

Status: 0.x, in development; rules not yet published.

See the [design spec](docs/superpowers/specs/2026-11-21-universal-software-standard-design.md).
